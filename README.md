# Sistema de Registro de Ponto – SESI/SENAI

## Introdução

O registro de ponto é uma ferramenta utilizada para controlar os horários de entrada, saída e intervalos dos funcionários e alunos em ambientes de trabalho e aprendizagem. No SESI/SENAI, esse tipo de controle é importante para organizar a rotina, acompanhar a frequência e manter os horários registrados de forma correta.

## Objetivo do Projeto

O objetivo deste projeto é desenvolver um sistema de registro de ponto simples e eficiente, capaz de registrar informações como nome do usuário, data, horário de entrada, horário de saída e intervalo. O sistema busca facilitar o controle da frequência e tornar o processo mais organizado.

## Funcionamento

O usuário realiza seu acesso ao sistema por meio de um login. Após entrar, pode registrar o horário de entrada e, posteriormente, os horários de intervalo e saída. As informações ficam organizadas para facilitar a consulta e o acompanhamento dos registros.

O sistema pode utilizar **HTML, CSS e JavaScript** em sua construção. O HTML é responsável pela estrutura da página, o CSS pela aparência visual e o JavaScript pelas funcionalidades e interações do sistema.

## Importância

Um sistema de registro de ponto ajuda a reduzir erros nos registros manuais, facilita a organização das informações e permite um acompanhamento mais eficiente da frequência. Além disso, proporciona aos usuários uma maneira rápida e prática de registrar seus horários.

## Conclusão

O desenvolvimento de um sistema de registro de ponto para o ambiente SESI/SENAI demonstra como a tecnologia pode ser utilizada para solucionar problemas do dia a dia. Com uma interface simples e funcionalidades adequadas, o sistema pode contribuir para melhorar a organização, o controle de horários e a eficiência dos registros.
